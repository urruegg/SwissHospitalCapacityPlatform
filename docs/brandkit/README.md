# Curavias — Brand Kit v2

**Curavias** · *Swiss Hospital Capacity Copilot* · curavias.ch
Tagline: *Every patient's path, in Swiss hands.*

The official, self-contained brand kit for solution branding. Start with **`Curavias-Brand-Guidelines.md`** (or `.docx`).

## Contents

| Folder | What's inside |
| --- | --- |
| `logo/` | Horizontal logo, logo-with-tagline, standalone symbol (SVG + PNG) |
| `icon/` | App icon (SVG + PNG) and `favicons/` (16–1024 px) |
| `color/` | Fluent UI color system: `curavias-theme.ts`, `curavias-tokens.json`, `curavias-tokens.css`, `curavias-powerbi-theme.json`, `curavias-color-swatches.png`, and the color spec (`.md`/`.docx`) |
| — | `Curavias-Brand-Guidelines.md/.docx` — master guidelines |

## At a glance

- **Primary colour:** Success Green `#17B890` (dark text on green — see accessibility note)
- **Secondary colour:** Curavias Blue `#365B7D` (nav, white-text buttons, wordmark)
- **Icon story:** start → care → success (the care pathway)
- **Fluent v9:** `import { curaviasLightTheme } from './color/curavias-theme'`

SVG files are the scalable masters; PNGs are convenience previews.
