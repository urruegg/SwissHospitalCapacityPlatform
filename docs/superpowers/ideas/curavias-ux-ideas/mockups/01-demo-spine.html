Proposed Demo Spine — three acts

Reframing the Sprint 20 shell into one guided end-to-end story. Simulated data only, no PHI.

Act 1 · Audience: Executives + Persona

START — set the scene, then launch

A short, confident opening that frames the capacity challenge and hands the visitor into the journey.

  • Brand + mission hook (Curavias, one line)
  • The capacity squeeze in a single glance
  • “Choose your role” launcher into the Main act
  • Live-vs-simulated badge for honesty
Act 2 · Audience: Each persona role

MAIN — the working app, per role

One tailored surface per role, with a docked AI copilot and the access-lens deciding what each role sees.

  • Bed Manager · Discharge Coordinator
  • OR Planner · Staffing Lead
  • Crisis / Command view
  • Docked agent copilot + RBAC access-lens + EN/DE/FR/IT
Act 3 · Audience: C-level (CEO/COO/CIO/CTO/CISO)

BACKSTAGE — how it was established (KISS)

A calm, simple “how this was built” view for the C-suite — proof, not dashboards.

  • Built-by-agents story (a few tiles)
  • Data platform: Fabric + FHIR at a glance
  • Governance / Swiss DSG in one panel
  • DEV → SIT → PROD delivery, simply shown

Flow: START  →  MAIN (pick a role, do the work)  →  BACKSTAGE (C-level proof) — with a persistent way to jump between acts.
