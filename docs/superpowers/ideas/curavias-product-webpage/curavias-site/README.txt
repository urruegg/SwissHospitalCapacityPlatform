CURAVIAS — WEBSITE MOCKUP (HTML)
Microsoft Innovation Hub Zürich — Showcase
=================================================

WHAT THIS IS
------------
A starting-point HTML mockup of the Curavias website, built from the Curavias BOM
(curavias-bom.zip). Each page is a single self-contained .html file — open it by
double-clicking; images and styles are embedded, no internet needed.

PAGES
-----
- index.html         Main landing page — all 13 sections (hero → footer):
                     hero, KPIs, "Der Mensch entscheidet", CIO-Challenger + 7
                     decisions, patient path, 7 agents, 3 experiences, security,
                     business value (BVA), reviews, next steps, footer.
- agents.html        The seven AI-copilots in detail (table + cards) + engineering agents.
- architecture.html  Layered architecture, component topology, end-to-end flow,
                     Bronze→Silber→Gold + PHI gates, delivery pipeline, Swiss residency.

MEDIA IN THIS MOCKUP
--------------------
- Photos (3): AI-generated starter images (command center, "human decides",
  Swiss data context) — embedded in the HTML and also in /assets as .jpg.
  Replace with approved Brand Central photography (see BOM 05-brand-central-assets-bom).
- Diagrams/icons/charts: hand-built inline SVG (logo, patient path, agent icons,
  whiteboard, BVA bar chart, delivery pipeline) — fully editable in the HTML.
- Video: styled placeholder block in the "3 Erlebnisse" section (VID-02).
  Swap in real video per BOM 04-website-content-bom.

TO CUSTOMISE
------------
- Text: edit directly in the HTML (all copy is German, from the flyer/north star).
- Colours/typography: CSS variables in the <style> block (:root).
- Photos: replace the <img src="data:..."> with your Brand Central assets, or
  point to the .jpg files in /assets.
- Microsoft logos: not included (Brand Central is sign-in only) — add per the BOM.

NOTE
----
Showcase only — synthetic data, advisory-only AI, not a medical product, not for
clinical use. Microsoft marks must follow Brand Central usage rules.
