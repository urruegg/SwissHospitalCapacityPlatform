# Curavias — Layered IQ Operating Model (visual reference)

A standalone, reusable HTML visual of the Curavias layered **IQ operating
model**: the five stacked IQ layers (Work / Foundry / Fabric / DevSecOps /
Governance IQ) plus the cross-cutting **Process IQ** patient-flow spine, with an
**MVP vs Target** colour split (green = MVP, dashed blue = Target).

## Use

Open [`index.html`](index.html) directly in a browser — it is self-contained
(no build step, no server, no external assets).

## Origin and reuse

Produced in the Sprint 34 SD refactor brainstorming session
([design spec](../../specs/2026-07-28-sprint-34-sd-iq-layer-refactor-design.md)).
The GitHub-renderable Mermaid translation lives in
[`docs/SD.md`](../../../SD.md); this HTML is the polished, presentation-ready
form kept here so it can be reused in other contexts (decks, demos, briefings).

Keep the two in sync: if the layer model changes in `SD.md`, update this visual
(and vice versa).
