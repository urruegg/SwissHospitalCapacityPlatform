The first frontier · invented the Journai way

Capacity Forecast — live in 90 days, 1 human + agents

Journai’s lesson: don’t plan for months — start small, prove value in weeks, then scale. Curavias’ first identified frontier is the 72-hour capacity forecast (OOA): delivered by one human orchestrating supporting agents, validated with real hospital competency.

Frame & GroundDAY 0–30
  • Pick one frontier use case: the 72-h forecast
  • Ground on governed synthetic data — no PHI
  • Calibrate to the hospital’s real demand pattern
  • Name the human owner & the challenger role
Build & ProveDAY 30–60
  • OOA forecast live in SIT, cited & audited
  • DC-INSIGHT prescriptive beats + HITL gate
  • Review with bed & ops roles — challenge & refine
  • Measure forecast error at operational horizon
Operate & ScaleDAY 60–90
  • Promote to PROD Switzerland North via approval gate
  • OOA→DCA handoff for discharge coordination
  • Daily command-center cadence adopted
  • Next frontier lever chosen from evidence
Delivered pattern, not a promise: the forecast agent (OOA) is already live in PROD Switzerland North on synthetic data. The 90-day frame is the repeatable path for a new provider.

The whole platform — 29 sprints of requirements, architecture, code, infrastructure and compliance evidence — was delivered by a single person acting as an “agent boss”, with GitHub & Foundry agents doing the build.

1

Organize around outcomes, not roles

Every sprint is one tracker issue → small vertical slices → squash PRs. GitHub is the single control plane.

2

Human–agent teams

Agents open, update and green pull requests in parallel worktrees; a human merges every PR — agents never self-merge.

3

Trust & governance by design

ADRs, PR traceability, security & compliance gates, and PHI four-gate enforcement are native, not bolted on.

4

Evidence-first, measurable

Every release is auditable; requirements map to FR/NFR IDs; value tracked against the BVA baseline.
